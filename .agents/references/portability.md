# Перенос на другое устройство

Читай при первом запуске на новом устройстве, отсутствии инструмента/store или восстановлении checkout. Все ссылки `.agents/...` в инструкциях разрешаются от корня этого репозитория. `AGENTS.md` — автоматически обнаруживаемое ядро; references не загружаются автоматически: читай их только по указанному триггеру. `.agents/skills/*/SKILL.md` — проектные skills; Claude globs и произвольные `agent.md` не являются автоматическим источником Codex.

Переноси этот Git-репозиторий вместе с `.agents` и `.codex`; глобальный AGENTS и личные skills не обязательны для проектных правил. Не копируй credentials, trust/security-настройки и состояние чужих сессий. `.env` и доступы восстанови отдельно через штатные секреты. Недоступный connector/CLI — явный blocker только соответствующей операции; не подменяй его данные догадкой.

Пути из истории/evidence остаются историческими идентификаторами. Не переписывай receipts, hashes, claims и immutable artifacts ради смены устройства. Для активных конфигураций сначала найди текущий основной checkout через `git worktree list --porcelain`; путь worktree не равен каноническому root. Read-only работа не требует worktree или регистрации planning.
