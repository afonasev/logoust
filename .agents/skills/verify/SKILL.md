---
name: verify
description: Проверить изменения logoust_assistant минимальным набором QA по diff. Использовать для проверки текущей задачи; полный прогон только по отдельной явной команде человека.
---

1. Запиши baseline, diff, изменённое поведение и необходимые зависимости.
2. Выбери и сообщи команды до запуска. Для документации и конфигурации проверь форматы, ссылки и diff без запуска бота и pytest.
3. Для Python выбери затронутые файлы/контракты: `uv run ruff check <files>`, `uv run ruff format --check <files>`, type-check по необходимости и `uv run pytest --no-cov tests/test_<affected>.py`.
4. `--no-cov` отключает только общий coverage gate для affected-прогона; не меняй assertions, seeds, длительности или timeout. 100% общего покрытия этим прогоном не подтверждается.
5. Полный `make check`, `make test`, pytest без селектора и ручной pytest hook разрешены только по отдельной команде человека. `make check` и `make lint` изменяют файлы; сначала прочитай маршрут Makefile.
6. При ошибке покажи причину и исправляй только в разрешённом scope. Повторяй затронутую проверку после исправления, без автоматического расширения до full.
7. Сообщи фактический результат, пропуски и ограничения; не подменяй NotRun успешной проверкой. Не запускай polling, миграции рабочей БД и deploy ради проверки кода.
