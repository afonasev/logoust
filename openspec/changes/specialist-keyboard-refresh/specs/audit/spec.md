## ADDED Requirements

### Requirement: Подтверждение существующего подключения клиента

Бот **SHALL** записывать ответ привязанному клиенту на `/start` без payload как `message` с событием `connection_confirmed`, полным текстом и статусом доставки; при ошибке доставки сохраняется `failed` с причиной.

#### Scenario: Клиент получил подтверждение подключения

- **WHEN** привязанный клиент получает ответ `already_linked`
- **THEN** в журнале выбранной карточки появляется `connection_confirmed` со статусом `sent`
