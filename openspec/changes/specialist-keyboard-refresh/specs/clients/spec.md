## ADDED Requirements

### Requirement: Голый /start от привязанного клиента подтверждает подключение

Бот **SHALL** при получении `/start` без payload от пользователя, который не является специалистом, но привязан как клиент (найден по `clients.telegram_chat_id`), ответить текстом `[start].already_linked` вместо `[start].no_token`. Никакие карточки клиентов при этом не изменяются.

#### Scenario: Клиент нажал /start без ссылки

- **WHEN** пользователь, привязанный как клиент по `telegram_chat_id` и не являющийся специалистом, отправляет `/start` без payload
- **THEN** бот отправляет текст из ключа `[start].already_linked`
- **AND** ни одна карточка клиента не изменяется

#### Scenario: Незнакомый пользователь по-прежнему получает no_token

- **WHEN** пользователь, не привязанный ни как специалист, ни как клиент, отправляет `/start` без payload
- **THEN** бот отправляет текст из ключа `[start].no_token`
